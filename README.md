# 📋 Task Management App

A simple and user-friendly **Task Management Application** designed to help users create, organize, track, and manage their daily tasks efficiently.

## 🚀 Features

* ➕ Create new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📌 Track task status
* 🔍 Search and manage tasks easily
* 📱 Responsive and user-friendly interface
* ⚡ Fast and simple task management
* 🎯 Helps users stay organized and productive

## 🛠️ Technologies Used

* CSS
* JavaScript

## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

* Git
* Node.js
* npm

### 1. Clone the Repository

```bash
git clone https://github.com/BalaTejaswniPratthi/Task-management-app.git
```

### 2. Navigate to the Project

```bash
cd Task-management-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npm run dev
```

or, depending on the project configuration:

```bash
npm start
```

### 5. Open in Browser

Open the local URL displayed in your terminal, for example:

```text
http://localhost:3000
```

## 📖 How to Use

1. Open the Task Management Application.
2. Add a new task using the task creation option.
3. Enter the required task details.
4. Save the task.
5. View your tasks from the task dashboard.
6. Update the task whenever required.
7. Mark completed tasks as finished.
8. Delete tasks that are no longer needed.

## 🎯 Project Objective

The main objective of this project is to provide a simple digital solution for managing daily tasks and improving productivity.

Instead of maintaining tasks manually, users can manage their work digitally from a single application.
